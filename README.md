# 李敏 · 个人简历与空间设计作品集

React + Vite 基础版本。图片与首页视频均为本地资源，无需依赖第三方图片服务。

## 预览

双击 `启动预览.cmd`，保持启动窗口打开，然后在浏览器访问 http://localhost:5173 。关闭窗口可停止预览。

有 Node.js 和 pnpm 的环境也可以执行：

```sh
pnpm install
pnpm dev
```

构建：`pnpm build`，输出为 `dist/`。可部署到支持单页静态网站的服务器。

## 内容与素材

- `src/data.js`：项目、工作经历和分类数据；所有项目均来自用户提供的项目集。
- `src/main.jsx`：页面结构与交互。
- `src/style.css`：色彩、排版、桌面及手机样式。
- `public/assets/`：从作品集 PPT 提取并压缩的真实项目图片、个人头像及背景视频。
- `public/assets/hero-light.mp4`：以成都天恒架空层阅读空间效果图制作的 10 秒慢运镜循环视频，呈现木格栅、窗景与自然光关系；并非现场实拍，可直接替换为后续提供的视频。
- `public/assets/portrait-cutout.png`：基于本人原始头像去背景的透明人物素材，仅用于个人介绍卡片，首页不展示人物。

## 单文件离线 HTML

运行 `pnpm pack:html`，生成上级“发布备份/李敏-个人简历与作品集-离线版.html”。图片、视频、样式及脚本全部嵌入文件，无需部署或原站点域名。仅包含当前页面引用的素材，重复引用共享同一媒体数据表。

导出程序自动校验脚本语法、嵌入媒体与原始文件逐字节一致性、工作经历时间、外部脚本与样式依赖。当前文件约 44 MB，106 个媒体资源，包含 22 个项目。

该格式需要支持 JavaScript 的浏览器运行。微信可能将 HTML 作为附件而非直接运行的网页，不能保证微信内直接显示；可以把文件保存后使用浏览器打开。当前自动预览工具不支持本地 file 协议，未完成本地浏览器或微信实测。
